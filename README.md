## Lab Topics

The repository contains separate C programs for the following questions:

1. Array Statistics
2. Reverse an Array
3. Linear Search
4. Swap Using Pointers
5. Sum of Array Using Pointer Arithmetic
6. Student Structure
7. Student Analysis
8. Dynamic Memory Allocation
9. Pointer to Structure
10. Dynamic Student Records
